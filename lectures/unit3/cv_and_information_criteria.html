Cross-validation and model selection criteria

We might first think to use our F-test to test the null hypothesis that the last \(K\) elements of \(\beta\) are zero. However, the problem is that these hypothesis tests are not independent of one another. (Why?) Choosing the \(K\) that minimizes the \(F\) statistic will use the data twice in a way that invalidates the hypothesis test.

Instead, we can form estimates of the MSE using held-out \[ \frac{1}{N} \sum_{n=1}^N(y_n - \boldsymbol{x}_n^\intercal\hat{\boldsymbol{\beta}})^2 \le \frac{1}{N} \sum_{n=1}^N(y_n - \boldsymbol{x}_n^\intercal\boldsymbol{\beta})^2. \]

In fact,

\[ \begin{aligned} \frac{1}{N} \sum_{n=1}^N(y_n - \boldsymbol{x}_n^\intercal\hat{\boldsymbol{\beta}})^2 ={}& \frac{1}{N} (\boldsymbol{Y}- \boldsymbol{X}\hat{\boldsymbol{\beta}})^T (\boldsymbol{Y}- \boldsymbol{X}\hat{\boldsymbol{\beta}}) \\={}& \frac{1}{N} (\boldsymbol{Y}- \boldsymbol{X}\boldsymbol{\beta}+ \boldsymbol{X}(\boldsymbol{\beta}- \hat{\boldsymbol{\beta}}))^T (\boldsymbol{Y}- \boldsymbol{X}\boldsymbol{\beta}+ \boldsymbol{X}(\boldsymbol{\beta}- \hat{\boldsymbol{\beta}})) \\={}& \frac{1}{N} \left\Vert\boldsymbol{Y}- \boldsymbol{X}\boldsymbol{\beta}\right\Vert^2 + \frac{1}{N} (\boldsymbol{\beta}- \hat{\boldsymbol{\beta}})^\intercal\boldsymbol{X}^\intercal\boldsymbol{X}(\boldsymbol{\beta}- \hat{\boldsymbol{\beta}}) + \frac{1}{N} 2 (\boldsymbol{Y}- \boldsymbol{X}\boldsymbol{\beta})^\intercal\boldsymbol{X}(\boldsymbol{\beta}- \hat{\boldsymbol{\beta}}) \\={}& \frac{1}{N} \left\Vert\boldsymbol{\varepsilon}\right\Vert^2 + \frac{1}{N} \boldsymbol{\varepsilon}^\intercal\boldsymbol{X}(\boldsymbol{X}^\intercal\boldsymbol{X})^{-1} \boldsymbol{X}^\intercal\boldsymbol{X}(\boldsymbol{X}^\intercal\boldsymbol{X})^{-1} \boldsymbol{X}^\intercal\boldsymbol{\varepsilon} - 2\frac{1}{N} \boldsymbol{\varepsilon}^\intercal\boldsymbol{X}(\boldsymbol{X}^\intercal\boldsymbol{X})^{-1} \boldsymbol{X}^\intercal\boldsymbol{\varepsilon} \\={}& \frac{1}{N} \left\Vert\boldsymbol{\varepsilon}\right\Vert^2 - \frac{1}{N} \left\Vert(\boldsymbol{X}^\intercal\boldsymbol{X})^{-1/2} \boldsymbol{X}^\intercal\boldsymbol{\varepsilon}\right\Vert^2 \\\le{}& \frac{1}{N} \left\Vert\boldsymbol{\varepsilon}\right\Vert^2 \approx \textrm{MSE}. \end{aligned} \]

Note that the under-estimation is precisely to the extent that the columns of \(\boldsymbol{X}\) are able to align with the true unobserved residual, \(\boldsymbol{\varepsilon}\).data. Note that the in-sample error underestimates the true MSE, simply because we find \(\hat{\beta}\) to minimize it:

There are a number of approximate criteria that try to correct the MSE for overfitting (AIC, BIC, adjusted \(R^2\)), but they hold only approximately and asymptotically. Instead, one can approximate the MSE directly by holding out some data.

In particular, if we leave out a single datapoint, and denote by \(\hat{\boldsymbol{\beta}}_{-n}\) the fit without the \(n\)–th datapoint, then the error on the left-out point is approximately unbiased for MSE, since \[ \begin{aligned} \textrm{MSE}_{-n} ={}& (y_n - \boldsymbol{x}_n^\intercal\hat{\boldsymbol{\beta}}_{-n})^2 \\ \mathbb{E}\left[\textrm{MSE}_{-n} \vert y_n, \boldsymbol{x}_n\right] ={}& y_n^2 - 2 y_n \boldsymbol{x}_n^\intercal\mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n}\right] + \boldsymbol{x}_n^\intercal\mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n} \hat{\boldsymbol{\beta}}_{-n}^\intercal\right] \boldsymbol{x}_n \\ \mathbb{E}\left[\textrm{MSE}_{-n}\right] ={}& \mathbb{E}\left[y_n^2\right] - 2 \mathbb{E}\left[y_n \boldsymbol{x}_n^\intercal\right] \mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n}\right] + \mathrm{trace}\left(\mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n} \hat{\boldsymbol{\beta}}_{-n}^\intercal\right] \mathbb{E}\left[\boldsymbol{x}_n \boldsymbol{x}_n^\intercal\right] \right) \\={}& \mathbb{E}\left[y_\mathrm{new}^2\right] - 2 \mathbb{E}\left[y_\mathrm{new}\boldsymbol{x}_\mathrm{new}^\intercal\right] \mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n}\right] + \mathrm{trace}\left(\mathbb{E}\left[\hat{\boldsymbol{\beta}}_{-n} \hat{\boldsymbol{\beta}}_{-n}^\intercal\right] \mathbb{E}\left[\boldsymbol{x}_\mathrm{new}\boldsymbol{x}_\mathrm{new}^\intercal\right] \right) \\={}& \mathbb{E}\left[(y_\mathrm{new}- \boldsymbol{x}_\mathrm{new}^\intercal\hat{\boldsymbol{\beta}}_{-n})^2\right], \end{aligned} \]

where the final line follows from the fact that \(x_n,y_n\) and \(x_\mathrm{new},y_\mathrm{new}\) have the same distribution. The only bias occurs from the fact that \(\hat{\boldsymbol{\beta}}_{-n}\) has a different distribution from \(\hat{\boldsymbol{\beta}}\) on the full data (in particular, it has a slightly larger variance). It follows that we can estimate the MSE using

\[ \hat{MSE}_{LOO} := \frac{1}{N} \sum_{n=1}^N\textrm{MSE}_{-n}, \]

the “leave-one-out” cross-validation estimator.

# Cross-validation and model selection criteria

We might first think to use our F-test to test the null hypothesis that the last $K$ elements
of $\beta$ are zero.  However, the problem is that these hypothesis tests are not
independent of one another.  (Why?)  Choosing the $K$ that minimizes the $F$ statistic
will use the data twice in a way that invalidates the hypothesis test.

Instead, we can form _estimates_ of the MSE using held-out 
$$
\meann (\y_n - \xv_n^\trans \betavhat)^2 \le \meann (\y_n - \xv_n^\trans \betav)^2.
$$

In fact,

$$
\begin{aligned}
\meann (\y_n - \xv_n^\trans \betavhat)^2 
={}& \frac{1}{N} (\Y - \X\betavhat)^T (\Y - \X\betavhat)
\\={}& \frac{1}{N} 
    (\Y - \X \betav + \X (\betav - \betavhat))^T 
    (\Y - \X \betav + \X(\betav - \betavhat))
\\={}& \frac{1}{N} \norm{\Y - \X \betav}^2 +
  \frac{1}{N} (\betav - \betavhat)^\trans \X^\trans \X (\betav - \betavhat) +
  \frac{1}{N} 2 (\Y - \X \betav)^\trans \X (\betav - \betavhat)
\\={}& \frac{1}{N} \norm{\resv}^2 +
  \frac{1}{N} \resv^\trans \X (\X^\trans \X)^{-1} \X^\trans \X (\X^\trans \X)^{-1} \X^\trans \resv 
  - 2\frac{1}{N} \resv^\trans \X (\X^\trans \X)^{-1} \X^\trans \resv
\\={}& \frac{1}{N} \norm{\resv}^2 -
  \frac{1}{N} \norm{(\X^\trans \X)^{-1/2} \X^\trans \resv}^2
\\\le{}& \frac{1}{N} \norm{\resv}^2 \approx \textrm{MSE}.
\end{aligned}
$$

Note that the under-estimation is precisely to the extent that the columns of $\X$ are able
to align with the true unobserved residual, $\resv$.data.  Note that
the in-sample error underestimates the true MSE, simply because we find
$\betahat$ to minimize it:


There are a number of approximate criteria that try to correct the MSE for overfitting
(AIC, BIC, adjusted $R^2$), but they hold only approximately and asymptotically.
Instead, one can approximate the MSE directly by holding out some data.

In particular, if we leave out a single datapoint, and denote by $\betavhat_{-n}$
the fit without the $n$--th datapoint, then the error on the left-out point is
approximately unbiased for MSE, since
$$
\begin{aligned}
\textrm{MSE}_{-n} ={}& (\y_n - \xv_n^\trans \betavhat_{-n})^2 \\
\expect{\textrm{MSE}_{-n} \vert \y_n, \xv_n} ={}& 
\y_n^2 - 2 \y_n \xv_n^\trans \expect{\betavhat_{-n}}
+ \xv_n^\trans \expect{\betavhat_{-n} \betavhat_{-n}^\trans} \xv_n \\
\expect{\textrm{MSE}_{-n}} ={}&
\expect{\y_n^2} - 2 \expect{\y_n \xv_n^\trans} \expect{\betavhat_{-n}}
+ \trace{\expect{\betavhat_{-n} \betavhat_{-n}^\trans} \expect{\xv_n \xv_n^\trans} }
\\={}&
\expect{\y_\new^2} - 2 \expect{\y_\new \xv_\new^\trans} \expect{\betavhat_{-n}}
+ \trace{\expect{\betavhat_{-n} \betavhat_{-n}^\trans} \expect{\xv_\new \xv_\new^\trans} }
\\={}&
\expect{(\y_\new - \xv_\new^\trans \betavhat_{-n})^2},
\end{aligned}
$$

where the final line follows from the fact that $\x_n,\y_n$ and $\x_\new,\y_\new$ have 
the same distribution.  The only bias occurs from the fact that
$\betavhat_{-n}$ has a different distribution from $\betavhat$ 
on the full data (in particular, it has a slightly larger variance).
It follows that we can estimate the MSE using

$$
\hat{MSE}_{LOO} := \meann \textrm{MSE}_{-n},
$$

the "leave-one-out" cross-validation estimator.
